CAMPUS PAS – Home Page Redesign

Files:
- index.html
- styles.css
- script.js

How to run:
1. Open this folder in VS Code.
2. Install/use Live Server (optional).
3. Open index.html or click "Go Live".

Images:
Search index.html for:
    IMAGE
or:
    image-placeholder

Replace the placeholder block with:
    <img src="YOUR-IMAGE-URL" alt="תיאור התמונה">

The Hebrew/English switch is already working.
The page is responsive for desktop, tablet and mobile.

This is the first home-page prototype. Existing page structure/text has been kept close to the current site while the visual design was rebuilt.
